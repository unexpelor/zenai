# Checklist Dokumentasi Lomba Teknologi Piranti Lunak

Dokumen ini disusun berdasarkan ketentuan lomba yang diberikan.

## Wajib disiapkan

- [ ] Pernyataan karya asli bermaterai.
- [ ] Pernyataan karya dibuat sendiri dan tidak sedang disengketakan.
- [ ] Pernyataan proses pembuatan dimulai setelah pengumuman resmi lomba.
- [ ] Proposal ringkas: latar belakang masalah, solusi, inovasi.
- [ ] Visualisasi aset desain UI: tipografi, logo, layout, ilustrasi, ikon, warna, dan elemen lain yang digunakan.
- [ ] Flowchart cara pakai aplikasi.
- [ ] Simulasi digital yang dapat dioperasikan langsung.
- [ ] Teaser video maksimal 3 menit.
- [ ] Source code di GitHub/cloud storage.
- [ ] Dokumentasi alur kerja.
- [ ] Dokumentasi penggunaan.
- [ ] Dokumentasi konfigurasi.
- [ ] Dokumentasi pengujian.
- [ ] Dokumentasi keamanan.
- [ ] Dokumentasi kompatibilitas.
