# Dokumentasi ZenAI

Dokumentasi ZenAI disusun untuk tiga kebutuhan: **pengguna**, **pengembang/penguji**, dan **demonstrasi lomba**.

## Peta Dokumentasi

| Dokumen | Kegunaan |
|---|---|
| `01_USER_MANUAL.md` | Panduan penggunaan aplikasi |
| `02_ARCHITECTURE.md` | Arsitektur teknis dan aliran data |
| `03_FLOWCHART.md` | Alur proses aplikasi |
| `04_SECURITY.md` | Keamanan, autentikasi, data, dan API |
| `05_TESTING.md` | Rencana pengujian dan evidence |
| `06_DEPLOYMENT.md` | Konfigurasi dan deployment |
| `07_COMPETITION_DOCUMENTATION_CHECKLIST.md` | Checklist kebutuhan lomba |
| `08_FAQ_TROUBLESHOOTING.md` | Bantuan pengguna dan troubleshooting |
| `09_DEMO_GUIDE.md` | Prosedur demo |
| `10_FEATURE_REFERENCE.md` | Referensi cepat semua modul |
| `11_DOCUMENTATION_INDEX.md` | Indeks dokumentasi berdasarkan audiens |
| `12_RELEASE_READINESS.md` | Pemeriksaan kesiapan submission/demo |

## Cara Membaca

**Pengguna baru:** 01 → 10 → 08

**Pengembang:** 02 → 04 → 06 → 08 → 12

**Penguji:** 05 → 08 → 12

**Persiapan lomba:** 03 → 07 → 09 → 12
